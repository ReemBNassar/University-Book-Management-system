Project Idea:
Exchanging university textbooks between university students in
an easy way.
Why this idea?
Currently in Gaza, we are suffering from extremely high prices,
and printing books is very expensive. Instead of printing a book
for single use, it can be used multiple times, thus reducing the
financial burden on everyone. The Engineering Club is currently
following this approach, but only through Instagram. If this
project is fully implemented, God willing, we will present it to the
Engineering Club for their use.
Problem the project solves:
1. Reusing the book multiple times instead of wasting it, as
printing it costs a lot.
2. Saving students money so that not everyone has to pay a large
amount for printing.
3. Using a printed book instead of a PDF book due to shipping
constraints.
Target users and use cases:
1.University students:
• Attach books they no longer need.
• Borrow a book they need.
2.Engineering Club:
• The project management team.
• Responsible for authorizing borrowing.
• Adding books that have been given to them.
• Deleting damaged books.
Brief description of the core features:
1.Dual-Interface Management System:
Student Interface: A simple UI for students to list their
surplus books or search for specific textbooks by course
code or title.
Engineering Club Dashboard: A specialized "Admin Panel"
for the club members to verify book arrivals, manage the
inventory, and approve borrowing requests.
2. Comprehensive Book Lifecycle Tracking:
• The system will automatically update the status of
each book:
• Available: Ready to be picked up from the club.
• Pending: A student has requested it, but it's not yet
picked up.
• Borrowed: Currently with a student (includes return
deadline).
• Damaged/Retired: Books that are no longer usable and
should be removed from the system.
3. Request & Verification Workflow:
Reservation System: Students can "Reserve" a book online.
4. Automated Inventory Analytics:
A feature for the Engineering Club to see which books are
in high demand and which subjects lack enough printed
copies, helping them prioritize collection efforts.
Comparison with existing solutions:
Current Instagram-based methods lack a searchable database
and automated status tracking, leading to high manual overhead
and potential human error.
On the website, everything is well-organized: a page for
requests, a page for available books, and so on.
Expected Impact or Benefit:
Economic Relief: Directly reduces the financial burden on
students in Gaza by eliminating the need for expensive new
prints.
Organizational Efficiency: Transforms the Engineering Club’s
manual work into an automated system, reducing errors and
saving time.
Data-Driven Decisions: Provides the club with statistics on which
books are needed most, allowing for better resource allocation.
Technology Stack & Tools:
Frontend (User Interface):
• HTML5: Used to build the structural framework of the
web pages, including book listings, request forms, and
admin dashboards.
• CSS3: Used for styling and layout design to ensure a
clean, professional, and user-friendly visual
experience.
• Bootstrap (Framework): A CSS framework to ensure
the website is fully responsive, allowing students to
access the platform easily from both mobile phones
and laptops.
Backend (Server-Side Logic):
• PHP: The core programming language used to handle
the system’s logic, such as managing user sessions,
processing book borrowing requests, and updating
book statuses (Available, Borrowed, Damaged).
Database Management:
• MySQL: A relational database management system
used to securely store and organize data for students,
book inventories, and transaction histories.
Development Environment:
• XAMPP / WAMP: A local server environment used for
hosting the PHP scripts and the MySQL database
during the development and testing phases.
